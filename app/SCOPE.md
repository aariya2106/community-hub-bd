# Project Scope: Community Hub

## Core Modules (MVP - High Priority)
1. **User Profiles & Authentication**
   - User sign-up, sign-in, and profile management using Supabase Auth.
2. **Food Listings**
   - CRUD operations for sharing available food items with the community.
3. **Volunteer Requests**
   - Posting and browsing volunteer opportunities.

## Stretch Features (Phase 2 - Low Priority)
- **Reputation System & Gamification** (Tracking points and events)
- **Advanced Issue Tracking & Moderation**
- **Real-time Notifications**
